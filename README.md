# homebrew-tap

Homebrew casks by [vladislavkovalskyi](https://github.com/vladislavkovalskyi).

```sh
brew install --cask vladislavkovalskyi/tap/saytype
brew install --cask vladislavkovalskyi/tap/vibecode24
```

| Cask | App |
|---|---|
| `saytype` | [saytype](https://github.com/vladislavkovalskyi/saytype): hold fn, talk, get formatted text. Offline Whisper dictation for macOS. |
| `vibecode24` | [Vibecode24](https://github.com/vladislavkovalskyi/vibecode24): keeps a MacBook awake with the lid closed while Claude Code, Codex and other AI coding agents run. |
